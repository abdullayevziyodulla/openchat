# OpenChat v0.2 release checklist

Version 0.2 adds Instagram professional accounts and durable campaign automation to the Telegram inbox. Meta App Review and live-account testing remain installation-specific external gates.

## Source and build

- [ ] Start from a clean checkout with Node.js 22.13+ and run `npm ci`.
- [ ] Run `npm run check:public`, `npm run test:unit`, `npm run lint`, `npm run typecheck`, and `npm run build`.
- [ ] Confirm `dist/server/wrangler.json` contains the D1 `DB` binding, R2 `MEDIA` binding, and both scheduled triggers.
- [ ] Review `THIRD_PARTY_NOTICES.md` and keep the OpenReply MIT notice in distributed source.
- [ ] Replace repository/operator placeholders in public pages and documentation.

## Data and secrets

- [ ] Take a D1 Time Travel bookmark, then apply migrations `0004`, `0005`, and `0006` in order to an existing v0.1 database.
- [ ] Confirm `OPENCHAT_ADMIN_PASSWORD`, `OPENCHAT_SESSION_SECRET`, Meta secrets, and optional AI keys are deployed as secrets rather than tracked variables.
- [ ] Create a private R2 bucket bound as `MEDIA` and configure an attachment lifecycle policy appropriate for the installation.
- [ ] Verify a backup restore against a disposable database before upgrading production.

## Meta configuration

- [ ] Register the exact OAuth callback and webhook URLs shown in **Settings → Channels**.
- [ ] Subscribe `messages`, `messaging_postbacks`, `messaging_seen`, `message_reactions`, and `comments`.
- [ ] Verify the app has the Instagram basic, messaging, and comment permissions required by `docs/instagram-setup.md`.
- [ ] Complete Advanced Access/App Review for accounts outside the app owner's assigned roles.
- [ ] Connect, refresh, disconnect, and reconnect an Instagram professional account without exposing its token to the browser or logs.

## Acceptance tests

- [ ] Receive Instagram and Telegram messages in the same inbox; send human text and supported attachments on both channels.
- [ ] Confirm Instagram AI replies stop outside the 24-hour window and that Human Agent delivery is disabled unless the app has approval.
- [ ] Deliver the same Instagram webhook twice and confirm the message/comment automation runs once.
- [ ] Exercise comment and DM keyword matching, any-text matching, selected-post, any-post, and next-Reel targeting.
- [ ] Exercise an opening postback, follower gate, public reply, three tracked HTTPS links, click analytics, and a delayed follow-up after a user interaction.
- [ ] Disable a comment webhook temporarily and confirm five-minute reconciliation finds a missed comment.
- [ ] Force a campaign failure, inspect it in **Settings → Operations**, verify provider state, then retry without repeating confirmed actions.
- [ ] Upload an Instagram image/video/audio/file and confirm Meta can fetch the signed URL while the dashboard attachment remains authenticated.
- [ ] Pause, edit, reactivate, and delete a campaign from the dashboard on desktop and mobile widths.

## Release

- [ ] Update `CHANGELOG.md` or release notes with migrations, required R2 binding, Meta permissions, and known limitations.
- [ ] Re-run `npm run verify` from the exact commit to tag.
- [ ] Tag `v0.2.0` only after installation-specific Meta acceptance tests pass.
