# OpenChat v0.1 release checklist

Version 0.1 is a Telegram-first, single-workspace release. Instagram is explicitly outside this release and must not be advertised as available.

## Automated release gates

- [x] `npm ci` completes from the checked-in lockfile.
- [x] `npm run test:unit` passes the authentication, credential, Telegram, D1 recovery, AI serialization, takeover, migration, and dashboard tests.
- [x] `npm run typecheck` passes.
- [x] `npm run lint` passes.
- [x] `npm run build` produces the Worker bundle plus `.openai/hosting.json` and all D1 migrations under `dist/.openai/drizzle`.
- [x] `npm audit --omit=dev` reports no production dependency vulnerabilities.

## Operator acceptance gate

Run this against the release deployment before tagging `v0.1.0`:

1. Sign in with the configured administrator password. Confirm five incorrect attempts are throttled.
2. In **Settings → Channels**, connect a fresh BotFather token and the deployment's public HTTPS URL.
3. Send a text message to the bot. Confirm one conversation and one inbound message appear after refresh.
4. Send a photo or document, then open it from the authenticated inbox.
5. Send a human reply and a native reply-to-message. Confirm Telegram receives one copy and the inbox records `sent`.
6. Optionally connect OpenRouter, test the assistant privately, then enable automatic replies and confirm one AI reply is sent for a burst of customer messages.
7. Start an AI reply and select **Take over**. The takeover request may wait for a send already in flight, but no AI message may begin after takeover succeeds.
8. In **Settings → Operations**, confirm there are no failed events or AI jobs. Exercise a synthetic/staging failure and verify **Retry** recovers it after a restart.
9. Redeploy without deleting D1. Confirm conversations, encrypted connection settings, and operations state remain present.
10. Record a D1 Time Travel bookmark before tagging the release and retain the rollback command from `docs/operations.md`.

Do not mark the release complete if any item above is unverified.
